Política de privacidad

Última actualización: 1 de octubre de 2026

Esta política se refiere únicamente al sitio público informativo de Auren. Auren es un proyecto personal de desarrollo de inteligencia artificial y automatización que se encuentra en desarrollo.

Datos que recopila esta página

Auren no configura cuentas, formularios, analítica, publicidad ni cookies en esta página. Tampoco solicita datos sensibles.

Alojamiento

El sitio está previsto para alojarse mediante GitHub Pages. Como proveedor de alojamiento, GitHub puede recibir datos técnicos necesarios para entregar el sitio, como la dirección IP, el agente de usuario y registros de la solicitud. Ese tratamiento se rige por la Declaración de privacidad de GitHub.

Contacto por correo

Si escribes a auren.assistant@gmail.com, se recibirán la dirección desde la que escribes, el contenido del mensaje y cualquier dato que decidas incluir. Esa información se utilizará para responder y dar seguimiento a la consulta.

Alcance

Esta landing no da acceso al asistente ni describe las prácticas de datos de futuras funciones o integraciones. Si el proyecto ofrece posteriormente una función pública que trate datos, su alcance y sus condiciones se documentarán antes de ponerla a disposición.

Cambios y consultas

La política puede actualizarse conforme evolucione el proyecto. La fecha de la versión vigente aparecerá al inicio de esta página. Para consultas de privacidad, escribe a auren.assistant@gmail.com.
